# もうミスらないtonight!の受付（クラウド同期版）

URLを開いた人は全員、同じデータを見て編集できます（ログイン不要）。
データは Cloudflare の Durable Object に保存されます。無料プランで動きます。

## ディレクトリ構成（GitHubのリポジトリ直下にこの形で置く）
```
(リポジトリのルート)
├─ wrangler.jsonc        … Cloudflare の設定
├─ README.md
├─ src/
│   └─ worker.js         … 同期API（/api/db, /api/flyer/<id>）
└─ public/               … 画面（ブラウザに配信されるファイル）
    ├─ index.html
    ├─ app.js
    ├─ style.css
    ├─ manifest.json
    ├─ sw.js
    ├─ TMPlogo.png
    ├─ icon-192.png
    └─ icon-512.png
```

## デプロイ（GitHub 連携）
1. このフォルダごと GitHub のリポジトリに置く（public / src / wrangler.jsonc の構成を崩さない）。
2. Cloudflare → Workers & Pages → Create → Import a repository。
3. プロジェクト名は wrangler.jsonc の name（tonight-register）に合わせる。

## 使い方
- 「新しい回を作る」→ 回のページから「受付」「バーカウンター」を開く。
- 回をアーカイブすると、開き直して編集したときに「変更を保存しますか？」が出る。
- 受付とバーカウンターは別々の端末で同時に使えます（部分ごとに新しい方を採用）。
- 同じ部分（例：受付）を2台で同時に編集すると、後から保存した内容が残ります。

## タイムテーブル・シフト
- 回のページ →「タイムテーブル・シフト」で、出番（時間・名前）とシフト（時間・役割・担当者）を登録。
- 回のページの「いま」欄に、現在の出番（と次の出番）、役割ごとの現在のシフト担当が自動表示される（開催日のみ・20秒ごとに更新）。
- 0〜5時台の時刻は「その夜の続き（翌日）」として扱う。

## 注意
- URLを知っている人は誰でも編集できます。共有範囲に注意してください。
- 以前の端末内データは、最初に開いたとき「過去データ（移行）」の回として引き継がれます。
